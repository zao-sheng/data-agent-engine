## 分层
| 层 | 前缀 | 含义 | 说明 |
|----|------|------|------|
| ODS | `ods_` | 贴源层 | 原始数据，不加清洗 |
| DWD | `dwd_` | 明细层 | 清洗后的明细事实，主题内原子粒度 |
| DWS | `dws_` | 汇总层 | 轻度汇总（日/周粒度），宽表 |
| ADS | `ads_` | 应用层 | 面向指标/应用的产出表 |
| DIM | `dim_` | 维度层 | 维表 |

## 分主题（示例，可扩展）
- 交易 `ord`（订单/支付/退款/消费）
- 用户 `usr`、商品 `prd`、营销 `mkt`、供应链 `scm`、财务 `fin`

## 表命名
格式：`{layer}_{domain}_{subject}_{粒度后缀}`
- 明细：`dwd_ord_pay_di`（`_di` 日增量 / `_df` 日全量）
- 汇总：`dws_ord_pay_1d`、`ads_ord_gmv_1m`（`_1d` 日 / `_1m` 月 / `_1w` 周）
- 维表：`dim_product`、`dim_store`

## 字段命名
- 全小写 snake_case；主键/外键统一 `*_id`；
- 事实表分区列统一 `dt`（`yyyyMMdd`），业务日期与分区同日；
- 必要过滤标志统一 `is_valid`（1=有效 0=无效）；
- 金额字段 `*_amt`、数量 `*_cnt`、比率 `*_rate`，并在 COMMENT 标注单位与口径。

## 强制约束
1. 任何 ETL 产物（DDL/任务）必须遵守上表命名规范，禁止自造命名；
2. 新建表前必须查重（避免与既有表/对象重复或冲突）；
3. 新建对象/指标必须注册进 Ontology（`ontology/` 目录），否则 Agent 无法检索使用。
