# 路径 B：探索性长尾查询（兜底）

仅当满足以下全部条件才走本流程：
1. `semantic_translate` 返回错误，且根因不是「缺映射/表未就绪/MQL 歧义」（这些应回 A 流程）；
2. 用户确属探索性查询（Ontology 无对应物）。

## 流程
1. **候选表召回**：用 `mcp__dataagent__ontology_search` + `ontology_traverse` 找到最接近的
   事实对象与表；不猜表名（物理表只出现在翻译引擎输出，不进入你的推理上下文）。
2. **受限生成**：直接编写 SQL（仅 SELECT；只允许白名单函数；必须带 dt 分区条件；
   必须带 required_filter（is_valid=1 等）；行数 ≤ 1000）。
3. **校验**：`mcp__dataagent__execute_sql` 沙箱执行（只读）。
4. **人工确认标记**：回答必须声明：
   「⚠️ 兜底路径生成（非注册口径），建议人工核对后使用」
5. **治理反馈**：把该查询记入反馈（供 Ontology 治理补充映射/注册指标）。

## 禁止
- 禁止写库/DDL/任何非 SELECT 语句；
- 禁止把物理表名/字段名作为「口径」告诉用户；
- 禁止绕过校验链直接返回。
